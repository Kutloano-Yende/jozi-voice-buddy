Jozi Buddy

A real-time voice AI agent powered by Amazon Nova Sonic and Strands Bidi Agents.

View the code on GitHub

  • Real-time voice

    Talk and listen at the same time. Interrupt Jozi Buddy mid-sentence and it stops to listen.

  • Powered by Nova Sonic

    Speech-to-speech on Amazon Bedrock, with the Nova Sonic model in us-east-1.

  • Built with Kiro

    Built step by step in the Kiro IDE, with Kiro as the pair-programmer.

How to run it locally

git clone https://github.com/Kutloano-Yende/jozi-voice-buddy.git
cd jozi-voice-buddy
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
aws configure
python voice_agent.py

Tech stack

  • Python
  • Strands Agents (Bidi)
  • Amazon Nova Sonic on Amazon Bedrock
  • Kiro IDE
